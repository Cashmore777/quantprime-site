How Compounding Works

  • Each period's return is calculated on the new balance, not the original
  • Small, consistent returns grow exponentially over time
  • 0.15%/day compounded = ~48% annual return (not 0.15 × 252 = 38%)
  • The calculator uses accurate compound interest: Balance × (1 + rate)^periods
  • Trading days assumed: 5/week (252/year), 21/month
